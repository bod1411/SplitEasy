# Split Easy iPhone App - Replit Development Prompt

## Overview
Create a React Native iPhone app called "Split Easy" for expense sharing among friends during trips, vacations, and group activities. The app should be simple, intuitive, and mobile-optimized with a clean, modern design.

## Core Functionality

### 1. Friend Management
- Add friends to the group (starting with "You" as default)
- Remove friends from the group (except "You")
- Display all friends in a clean list format
- Prevent duplicate friend names

### 2. Expense Tracking
- Add expenses with:
  - Description (e.g., "Gas for road trip", "Dinner at restaurant")
  - Amount (numeric input)
  - Who paid (dropdown selection from friends list)
- Display all expenses in a scrollable list
- Allow removal of individual expenses
- Show payer name and amount for each expense

### 3. Settlement Calculation
- Calculate total expenses automatically
- Determine per-person share (total ÷ number of friends)
- Calculate who owes money and who should receive money
- Minimize number of transfers needed for settlement
- Show settlement details in expandable section

## Design Requirements

### Visual Design
- **Color Scheme:**
  - Primary: Indigo/Blue gradient background (#EBF4FF to #E0E7FF)
  - Accent colors: Green for money (#059669), Blue for totals (#2563EB), Purple for settlements (#7C3AED)
  - Background: White cards with subtle shadows
  - Text: Dark gray (#374151) for primary, lighter gray (#6B7280) for secondary

### Layout Structure
- **Header:** App title "Split Easy" with tagline
- **Two-column grid on larger screens, single column on mobile:**
  - Left: Friends management section
  - Right: Add expense section
- **Full-width sections below:**
  - Expenses list (when expenses exist)
  - Settlement summary with statistics cards
  - Settlement details (expandable)

### UI Components
- **Cards:** White background, rounded corners, drop shadows
- **Buttons:** Rounded, colored backgrounds with hover effects
- **Inputs:** Border styling, focus states with colored borders
- **Icons:** Use React Native Vector Icons (Ionicons)
  - Users icon for friends section
  - Dollar sign for expenses
  - Calculator for settlement
  - Plus for adding items
  - Trash for removing items
  - Checkmark for settlements

## Settlement Algorithm
The app should calculate the most efficient way to settle debts:
1. Calculate how much each person paid vs. their fair share
2. Identify who owes money (negative balance) and who should receive money (positive balance)
3. Match debtors with creditors to minimize number of transactions
4. Return array of settlement instructions
